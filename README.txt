まちしるべ — 架空のMEO対策会社ホームページ

使い方：ZIPを展開し、index.htmlをブラウザで開いてください。
HTML・CSS・JavaScriptのみで動作し、インストールやビルドは不要です。
スマートフォンにも対応しています。

ファイル：
index.html：ページ構成・文章
style.css：デザイン・レスポンシブ対応
script.js：プラン選択・フォームのデモ動作

会社名・店舗・料金・サービス内容は架空です。
フォームは入力チェックのみ行い、外部への送信や保存はしません。
実運用時は企業情報・契約条件・プライバシーポリシーを整備し、フォーム送信機能を別途接続してください。
地図・店舗画像はCSSで制作したイメージであり、Googleマップの実データではありません。
